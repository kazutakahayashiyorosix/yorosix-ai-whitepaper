# YOROSIX AI: Machines That Work Together

**One machine is small. Machines that can rely on each other, and on people, can do together what none of them can do alone.**

- Read the white paper: [English](whitepaper/en.md) · [日本語](whitepaper/ja.md)
- Web version and live demo: https://kazutakahayashiyorosix.github.io/yorosix-ai-whitepaper/
- Demo source: [demo/index.html](demo/index.html) (open it in any browser; no install)

The demo shows three kinds of single-function robots (one opens doors, one grips, one carries). Working alone, none of them can finish a job. Asking each other, and asking a person to plug them in when their battery runs low, they do. The demo chooses whom to ask with a simple rule and does not contain YOROSIX AI's methods, which are patent pending.

# YOROSIX AI：力を合わせる機械

**1台の機械の力は小さい。互いに、そして人に頼り合える機械なら、1台ではできないことを一緒に成し遂げられる。**

- ホワイトペーパー：[日本語](whitepaper/ja.md) · [English](whitepaper/en.md)
- Web版と動くデモ：https://kazutakahayashiyorosix.github.io/yorosix-ai-whitepaper/ja/
- デモのソース：[demo/index.html](demo/index.html)（ブラウザで開くだけで動きます）

デモには3種類の単機能ロボット（ドアを開ける・つかむ・運ぶ）が出てきます。ひとりで働くと、どれも仕事をやり切れません。互いに頼み合い、電池が減ったら人に充電を頼むと、仕事が片付きます。デモの頼む相手の選び方は単純な決まりで、YOROSIX AI の方法（特許出願中）は含んでいません。
